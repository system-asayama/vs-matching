# vs-matching

空手大会のトーナメント表を、選手の強さ・経歴・体格・所属道場に応じて自動で作成するアプリです。
Docker Compose (Flask + PostgreSQL) で動きます。

## 機能

### ログイン
- ロールは **管理者 (admin)** と **利用者 (user)** の2種類
- 最初の管理者は **ブートストラップ** で登録する
  - 管理者が1人もいない状態でアクセスすると `/setup` に誘導され、そこで最初の管理者を登録する
  - 登録後 `/setup` は自動的に無効になる
  - 自動デプロイ向けに、環境変数 `ADMIN_USERNAME` と `ADMIN_PASSWORD` を両方指定した場合は起動時に自動作成する
- 利用者の自己登録は無く、**管理者だけが利用者を登録**できる
- パスワードはハッシュ化して保存。8文字以上

### 選手管理（管理者）
- 氏名・ふりがな・性別・生年月日・身長・体重・帯（無級〜六段以上）・経験年数・戦績・所属道場を登録
- CSV による一括登録（テンプレートあり。UTF-8 / Shift_JIS 対応）
- **強さスコア** を自動計算: 帯1段階 = 10点、経験1年 = 2点（上限20年）、1勝 = 3点、1敗 = -1点、勝率ボーナス最大10点

### 大会・階級（管理者）
- 大会に複数の **階級** を作る。階級ごとに性別・年齢・体重・帯の出場条件を設定
- 条件に合う選手を **一括エントリー**、または個別に追加・除外
- 同じ大会の別の階級に二重エントリーはできない

### トーナメント表の自動生成
1. 強さスコア順にシードを決める
2. 標準シード配置（1位と2位は決勝まで当たらない）で枠に割り当て。人数が2の累乗でない場合は上位シードが不戦勝
3. **同じ道場同士の1回戦を回避**（シードが近い相手との入れ替えで解消。ON/OFF 可）
4. 1回戦の各組に **注意マーク** を表示（同じ道場・体重差・身長差・帯差・年齢差）
- 生成後も1回戦の枠を **手動で入れ替え** 可能
- 試合ごとに勝者を入力すると次の回戦に自動で進む。優勝者を表示。結果の取り消しも可
- 大会を **公開** すると利用者がトーナメント表を閲覧できる（閲覧のみ）

## 画面

| パス | 権限 | 内容 |
|---|---|---|
| `/setup` | 未設定時のみ | 最初の管理者を登録 |
| `/login` | 全員 | ログイン |
| `/tournaments` | ログイン済み | 公開中の大会とトーナメント表の閲覧 |
| `/settings` | ログイン済み | 表示名・パスワード変更 |
| `/admin/fighters` | 管理者 | 選手一覧・登録・編集・CSV取り込み |
| `/admin/tournaments` | 管理者 | 大会一覧・作成・公開切り替え |
| `/admin/tournaments/<id>` | 管理者 | 階級の追加 |
| `/admin/divisions/<id>` | 管理者 | エントリー管理・トーナメント表の生成・入れ替え・結果入力 |
| `/admin/users` | 管理者 | 利用者一覧、ロール変更、停止/再開、パスワード再設定、削除 |

## 起動

```bash
docker compose up --build
```

`http://localhost:8080` を開くと初期セットアップ画面が表示されます。

### 環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `WEB_PORT` | `8080` | ホスト側ポート |
| `SECRET_KEY` | `dev-secret-change-me` | セッション署名鍵。本番では必ず変更 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 未設定 | 両方指定時のみ初期管理者を自動作成 |
| `DATABASE_URL` | compose で設定 | 未設定時はローカル SQLite (`instance/app.db`) |

## ローカル開発（Docker なし）

```bash
pip install -r requirements.txt
python app.py
```

`http://localhost:8000` で起動します（SQLite 使用）。シェルに別プロジェクトの `DATABASE_URL` が入っている場合は外してください。

## テスト

```bash
python -m pytest -q
```

## 構成

| ファイル | 内容 |
|---|---|
| `app.py` | アプリ生成、ログイン、利用者管理 |
| `auth.py` | セッション・アクセス制御 |
| `models.py` | User / Fighter / Tournament / Division / Entry / Match |
| `bracket.py` | 強さスコア・シード配置・同道場回避・注意判定（DB非依存） |
| `tournament.py` | 選手・大会・階級・トーナメント表のルーティング |
